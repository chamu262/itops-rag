IT Operations : Device Naming and Asset Tagging Standard

Created by Endpoint Engineering, last modified on Mar 2, 2026

Purpose

One naming scheme for every device makes tickets, inventory and logs easy to match. Names are set automatically by Jamf and Intune; nobody should rename a device by hand.

Name format

KC-<SITE>-<TYPE>-<ASSET>

PartValuesNotes
KCFixedCompany prefix
SITESTO, LON, AUS, LIS, REMOffice the person belongs to; REM for fully remote staff
TYPEMBP (MacBook Pro), MBA (MacBook Air), MAC (desktop Mac), WL (Windows laptop), WD (Windows desktop), IPH (iPhone), IPD (iPad), MTR (meeting room device), PRN (printer)Two or three letters
ASSETFive digits, zero paddedFrom the asset tag, not the serial

Examples: KC-STO-MBP-04217, KC-LON-WL-03311, KC-AUS-MTR-00412. Printers use floor and sequence instead of asset number, for example KC-STO-PRN-301 (floor 3, first printer).

Windows names are limited to 15 characters by NetBIOS. KC-LON-WL-03311 is exactly 15. Do not add suffixes.

Asset tags

  • Every device gets a printed asset tag KC-A-<5 digits> on the bottom case before it is issued. Tag numbers are issued in sequence by the CMDB.
  • The asset number is entered in Jamf (Asset Tag field) or Intune (device category plus the extension attribute assetTag) at the time the serial is registered.
  • Reseller deliveries for remote staff: the reseller applies tags from a pre-allocated range.

How names are applied

  • Mac: Jamf policy Set Computer Name runs at enrolment and reads site from the user's office attribute and asset from the Asset Tag field.
  • Windows: Autopilot sets a temporary name KCW-<serial>; a remediation script renames after enrolment and the change applies at the next restart.
  • iPhone and iPad: device name set by Jamf on enrolment.

When a device changes hands

The asset number stays with the device for its life. If the new user is in another office, the SITE part changes on re-enrolment. The CMDB keeps the history.

Finding a device name

  • Mac: Self Service > Device info, or scutil --get ComputerName
  • Windows: Settings > System > About, or hostname
  • Label on the bottom of the device
