IT Operations : Endpoint Security Baseline (macOS and Windows)

Created by Security Operations, last modified on Aug 30, 2026

This is the binding baseline for every Kestrel-owned laptop. Exceptions require a HELP ticket of type Security exception approved by Security Operations, with an end date of at most 90 days.

Purpose

Define the minimum security controls on company laptops and how they are enforced and measured. Jamf Pro enforces the macOS baseline and Microsoft Intune the Windows baseline. Compliance results feed Entra Conditional Access policy CA-020-Require-Compliant-Device and MeshGate posture checks (VND-005).

Accounts and authentication

  • macOS: local account created by Platform SSO at enrolment, password synchronised from Entra ID (RB-MAC-004). Managed admin kcadmin with password rotated by Jamf LAPS every 7 days and after each view.
  • Windows: Entra-joined only, Windows Hello for Business required. Windows LAPS rotates the built-in admin every 7 days.
  • MFA required for every sign-in to company apps; phishing-resistant methods required for admin roles (CA-030-Admin-Phishing-Resistant).

Measurement

Endpoint Engineering publishes a weekly compliance dashboard. Targets: 98% of active devices compliant, 100% with escrowed recovery keys. Devices not checking in for 30 days are marked non-compliant and reviewed by the Service Desk.
